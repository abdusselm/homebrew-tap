# abdusselm/homebrew-tap

Homebrew formulae for [panea](https://github.com/abdusselm/panea).

```bash
brew install abdusselm/tap/panea
```

`panea` is a local multi-pane terminal workspace for macOS — vertical tabs,
split panes, and attention rings for AI coding agents.

The formula installs only the JavaScript. The Electron runtime is downloaded to
`~/.panea/electron` on the first `panea --app`, because Homebrew rewrites Mach-O
files inside its Cellar and that invalidates the signature Electron ships with.

Formulae here are generated by `scripts/update-tap.mjs` in the panea repository;
edit that rather than the formula by hand.
